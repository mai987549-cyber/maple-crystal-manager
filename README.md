# Maple Manager Trace Final

Maple Task Manager風の別実装です。Firebase同期でPC/iPhone連携できます。

## 入っている機能
- ボス結晶管理
- 日課/週課/イベント
- ドロップ管理
- 貼り付けアイコン反映
- 欠片シミュ
- 成長記録
- 精算履歴
- 統計レポート
- VIPリセット
- PWA対応

## 注意
main.tsx / firebase.ts / style.css は src フォルダ内にあります。
GitHubに上書きするときはこのフォルダ構造のままアップロードしてください。
