# ボス結晶管理 Firebase版

ボス結晶の収益管理だけに絞ったWebアプリです。

## 主な機能

- Googleログイン
- PC / iPhone同期
- 6キャラ初期登録、あとからキャラ追加・削除可能
- ボス結晶価格マスタ
- キャラ別の討伐チェック
- PT人数割り
- キャラごとに高い順12個だけ売却対象として集計
- EXスウ、EX暗黒、EXセレン、EXカロス、EXカリーン入り
- iPhoneの「ホーム画面に追加」でアプリ風に利用可能

## セットアップ

### 1. Firebaseでプロジェクト作成

Firebase Consoleでプロジェクトを作成します。

### 2. Authenticationを有効化

Authentication → Sign-in method → Google を有効化します。

### 3. Firestore Databaseを作成

Firestore Databaseを作成します。

### 4. Webアプリを追加

Firebaseのプロジェクト設定から Webアプリを追加し、Firebase configを取得します。

### 5. `.env` を作成

`.env.example` をコピーして `.env` に変更し、Firebase configを入れます。

### 6. 起動

```bash
npm install
npm run dev
```

## Vercel公開

GitHubにこのフォルダをアップロードし、VercelでImportします。  
Vercelの Environment Variables に `.env` と同じ値を登録してください。

## iPhoneで使う

VercelのURLをSafariで開く → 共有 → ホーム画面に追加。

## 今回の修正

- 指定された結晶代をボス価格マスタの初期値として反映。

## キャラ情報貼り付け登録

設定タブに「キャラ情報を貼り付け登録」を追加しました。

対応する主な形式:
- `name`
- `basicStats.level`
- `basicStats.class`
- `apiResult.power.normal`
- `apiResult.power.hexa`
- `apiResult.bossResults`

ボス診断結果の `analytics` が以下の場合、自動で討伐済みにします。

- 瞬殺可能
- ソロ余裕
- ソロ可能
- ソロ限界

「戦闘員も含める」を選ぶと、戦闘員判定もPT人数つきで討伐済みにします。

## デザイン修正

- maple-task-manager風に、淡い背景・上部バー・収益カード・キャラカードグリッドへ変更。
- タブ名を「チェックリスト / 回収設定 / 統計 / 設定」風に変更。
- キャラカードをコンパクトなカード表示に変更。

## 選択制限・VIP枠

- 各キャラの選択可能ボス数を `12 + VIP追加枠` に制限。
- 設定タブからVIP追加枠を変更可能。
- 上限に達すると未選択ボスのチェックボックスを無効化。
- 同じボスの別難易度は同時選択不可。
- キャラ情報貼り付け登録時も、高い結晶代順に `12 + VIP追加枠` まで自動選択。

## ボス選択UI / VIPリセット表示

- 回収設定画面を、左にキャラ一覧・右にボスカード一覧のチェックリスト型UIへ変更。
- ボスカードをクリックして討伐対象を選択。
- VIPリセット対象ボスには、ボス名の右側に `VIP` ボタンを表示。
- VIPリセット対象は、アーケインまでのボス全部 + セレン / カロス / カリーン。
- リンボ、バルドリックス、最初の対敵者などはVIPリセット対象外。
- 同じボスの別難易度は同時選択不可。

## 自動統計

- 統計タブを追加。
- 手動精算なしで、選択中のボス結晶から自動で合計収益を計算。
- キャラクター別収支ランキングを表示。
- 4週/5週換算の月間見込みを表示。
- 選択中の結晶一覧を履歴風に表示。
- ボス価格マスタは設定タブへ移動。
